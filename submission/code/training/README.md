# Training code of A-hn

Each file is the one that ran, at its path under our working tree (`W` = the repository root; the training lanes are under
`W/.claude/worktrees/leadA-push3/x_push3/`). The scripts address data by those absolute paths, and the Docker image recreates
the same layout (`docker/README.md`, mode `train`). `SOURCES.sha256` lists each file's sha256. Section 4 of `docs/METHOD.md`
describes the training.
